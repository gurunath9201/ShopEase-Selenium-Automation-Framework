<h2 align="center">🚀 End-to-End E-Commerce Automation Testing</h2>

<p align="center">
  A Selenium WebDriver + Java automation framework designed to validate
  <b>login, products, cart, and checkout workflows</b>.
</p>

---

## ✨ Project Highlights

🎯 **60 automated test cases**

🔐 Login & authentication validation

🛍️ Product listing and product validation

🔄 Add / Remove / Re-add products

🛒 Cart functionality and navigation

💳 Complete checkout workflow

📦 Multiple-product checkout validation

🧾 Order confirmation validation

📊 Product sorting validation

🖼️ Product image validation

📸 Automatic screenshots on test failure

---

## 🧪 Testing Coverage

| Module | Coverage |
|---|---|
| 🔐 Login | Valid, Invalid, Locked User, Logout |
| 🛍️ Products | Product count, names, prices, sorting |
| 🖼️ UI Validation | Product images & descriptions |
| 🛒 Cart | Add, Remove, Navigation, Persistence |
| 💳 Checkout | Customer details & validation |
| 📦 Orders | Single & multiple product checkout |
| ✅ Regression | End-to-end checkout scenarios |

---

## ⚙️ Tech Stack

**Language:** Java 21  
**Automation:** Selenium WebDriver 4.40  
**Test Framework:** TestNG  
**Build Tool:** Maven  
**Browser:** Google Chrome  
**Design Pattern:** Page Object Model (POM)  
**Configuration:** Properties File  
**Reporting Support:** TestNG  
**Failure Handling:** Automatic Screenshots

---

## 🏗️ Framework Approach

This project follows the **Page Object Model (POM)** approach to keep:

✨ Tests clean  
✨ Locators maintainable  
✨ Reusable page actions  
✨ Test execution organized  
✨ Automation code scalable

---

## ▶️ Test Execution

The complete regression suite can be executed through **TestNG + Maven**.

The suite covers:

`Login → Products → Cart → Checkout → Order Confirmation`

---

## 📸 Failure Handling

When a test fails, the framework automatically captures a screenshot with the **test case name**, helping with faster debugging and defect analysis.
